# Тепловая карта комнаты — оконное приложение

Первая версия небольшого редактора геометрии для решения стационарного уравнения теплопроводности в плоскости. Использует **Python + Tkinter**, NumPy, SciPy и Pillow. Работает на Windows, macOS, Linux (с графическим окружением и установленным Tk).

## Установка и запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

На Linux при отсутствии Tk установите системный пакет `python3-tk`. На macOS рекомендуется Python с поддержкой Tk (например, с python.org).

## Как пользоваться

1. Нажмите **«Пример»**, чтобы загрузить комнату с четырьмя бетонными стенами, двумя окнами, нагревателем и отметкой улицы.
2. Нажмите **«Вычислить температуру»**. В окне появится тепловая карта; наведите указатель на неё для чтения температуры.
3. Инструмент **«Стена»**: нажмите и протяните мышью, задав отрезок; толщина задаётся в панели слева. Концы автоматически привязываются к близким концам существующих стен.
4. **«Окно»**: щёлкните по стене. Программа вырежет участок материала стены заданной длины и заменит его материалом окна.
5. **«Улица»**: щёлкните по пустой области *за пределами замкнутого контура стен*. Вся связная с этой точкой область воздуха станет улицей с фиксированной температурой.
6. **«Нагреватель»**: щёлкните внутри комнаты. Он задаёт небольшую область с фиксированной температурой.
7. **«Ластик»** или **правая кнопка мыши**: удаляют нагреватели, окна, стены; щелчок рядом с маркером улицы удаляет его.
8. Проект можно сохранять и открывать как JSON. Параметры теплопроводности и температура улицы настраиваются слева.

Редактор работает в области 8×6 метров, координаты экранного плана направлены вправо и вниз. Границы комнаты должны быть замкнуты. Геометрия «пикселизуется» с заданным шагом сетки: **толщина стен и окон должна быть существенно больше шага**, иначе возможны численные зазоры между внутренним воздухом и улицей. В первой версии рекомендуется `step = 0.10 м`, `wall thickness = 0.25 м` или уменьшить шаг до `0.05 м`.

## Математическая модель и ограничения

Вся плоскость расчёта (воздух внутри, бетон, окна и воздух снаружи) описывается **упрощённой стационарной двумерной теплопроводностью**:

\[
-\nabla\cdot(\lambda(x,y)\nabla T)=0.
\]

- Бетон, окно и воздух имеют разные `λ`.
- Помеченная область улицы: `T = T_out` (условие Дирихле).
- Нагреватель: `T = T_heater` (условие Дирихле).
- По внешней границе прямоугольной вычислительной сетки — нулевой нормальный поток (условие Неймана).
- На контактах материалов температура и нормальный тепловой поток непрерывны в дискретной модели.
- Матрица разреженная, симметричная и положительно определённая, пока все неизвестные области связаны с хотя бы одной областью фиксированной температуры.

В узле (ячейке) конечных объёмов используются коэффициенты между соседними ячейками, рассчитанные через **гармоническое среднее** теплопроводностей:

\[
\lambda_{ab} = \frac{2\lambda_a\lambda_b}{\lambda_a+\lambda_b}.
\]

Система собирается в формате CSR, затем решается методом сопряжённых градиентов `solveCG` из общего файла `../linsolver.py` с контролем невязки. Файлы `model.py` и `physics.py` не зависят от GUI: их можно импортировать отдельно (`assemble()` возвращает `A, b, raster, numbering`). Запускайте приложение из этого репозитория, чтобы общий модуль был доступен.

### Важно: это учебная модель, а не полноценный расчёт микроклимата

- **Нет конвекции, движения воздуха, излучения и теплоёмкости** — температура только стационарная, тепло передаётся исключительно теплопроводностью.
- Нагреватель с фиксированной температурой не равен реальному радиатору с заданной тепловой мощностью.
- «Окно» заменяет материал отрезка стены *с той же геометрической толщиной*. Это не детальная модель стеклопакета с реальным коэффициентом теплопередачи.
- `λ воздуха` в примере — **эффективный параметр 2D-модели**, его значение не следует интерпретировать как точную характеристику природного неподвижного воздуха.
- Температура зафиксирована в объёме области, обозначенной улицей; это не модель конвективного теплообмена с реальным наружным воздухом.
- Из-за дискретизации и работы с ячейками тонкие стены могут «протекать» через сеточные зазоры. При необходимости уменьшите размер ячейки.

Чтобы получить физически содержательные инженерные значения теплопотерь, следующий шаг — граничные условия Робина с реальными U-факторами окон и стен, модель смешанного воздуха и тепловых источников с мощностью в ваттах.
